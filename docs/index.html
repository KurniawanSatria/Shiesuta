Self-Hosting

Quick Installation

Deploy Shiesuta on your machine or VPS in under 3 minutes.

  • 1. Clone & Install Dependencies

    git clone https://github.com/KurniawanSatria/Shiesuta.git
    cd Shiesuta
    bun install

  • 2. Environment Configuration

    cp config.json.example config.json

    Open config.json and fill in your Discord Bot Token, Lavalink Node details, and Spotify API credentials.

  • 3. Lavalink v4 Server

    Shiesuta leverages Lavalink v4 for high performance audio processing. Ensure your Lavalink node is running and reachable via host/port specified in config.json.

  • 4. Launch

    bun start
Make sure to enable Guilds, Guild Voice States, Guild Messages, and Message Content in the Discord Developer Portal under the Bot tab.
FAQ

Frequently Asked Questions

Answers to common questions about using and hosting Shiesuta.

How do I invite Shiesuta to my Discord server?

Simply click the "Add to Discord" button on the navigation bar or hero section. Select your Discord server, grant the necessary permissions (voice connect, speak, send messages), and click Authorize.

Why does Shiesuta require Lavalink v4?

Lavalink offloads heavy audio encoding and decoding from the Node/Bun process into a specialized Java audio service. This guarantees zero audio stuttering, low CPU usage, and high-bitrate streaming for dozens of servers at once.

Can I play Spotify playlists directly?

Yes! Shiesuta automatically resolves Spotify track, album, and playlist URLs via Lavalink. Just paste any Spotify link into .play <link>.

How do I switch the language to Indonesian or Malay?

Use the command .set lang id for Indonesian, or .set lang ms for Malay. Use .set lang en to return to English. The setting is saved per server.

Is Shiesuta open-source and free to host?

Yes, Shiesuta is fully open-source on GitHub. You can freely fork, self-host on a personal VPS, Docker, or customize it for your private community.
